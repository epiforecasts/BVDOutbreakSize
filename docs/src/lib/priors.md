# Priors and latent submodels

Turing submodels for the epidemiological processes and the surveillance parameters: the delays, the generation interval, the reproduction number walk, the case-fatality ratio, ascertainment, laboratory behaviour and the isolation pathway.
Each is a named submodel so it can be swapped or fitted on its own.
