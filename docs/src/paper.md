# Paper

A short preprint describes how this work developed, the current model, its evaluation and the lessons learnt.
It is written in Quarto under [`paper/`](https://github.com/epiforecasts/BVDOutbreakSize/tree/main/paper) and pinned to a tagged release of this report, which serves as its supplement.

- [Paper source](https://github.com/epiforecasts/BVDOutbreakSize/blob/main/paper/main.qmd)
- [Latest rendered PDF and HTML](https://github.com/epiforecasts/BVDOutbreakSize/actions/workflows/paper.yml) (the `paper` artifact on the most recent run)

Render it locally with `task paper`, which needs [Quarto](https://quarto.org).
